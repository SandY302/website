# Sandeep Prajapati — Cybersecurity Portfolio

A free, responsive cybersecurity portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — mobile menu and footer year

## Run locally
Open `index.html` in a browser.

## Free hosting
You can host this website for free with GitHub Pages or Cloudflare Pages.

### GitHub Pages
1. Create a GitHub account.
2. Create a new repository, for example `sandeep-portfolio`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. In the repository, open Settings → Pages.
5. Select the main branch as the deployment source.
6. GitHub will provide your free website address.

## Optional CV
When you have a public CV PDF, add it to this folder as `Sandeep_Prajapati_Resume.pdf` and add a resume button in `index.html`.
